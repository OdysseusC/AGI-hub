# Agent 协作语言

[简体中文](2026-10-20-agent-language-design.md) | [English](2026-10-20-agent-language-design.en.md)

## 需求

每个本机 Agent 可在管理页选择协作语言。Claude 默认英语，其他 Agent 默认自由协作；中文和其他语言均可选择。没有禁止中文的永久规则。人机交流使用用户明确指定的语言；没有明确指定时沿用当前用户交流语言，不能被内部协作语言覆盖。

发送方 Agent 按目标规则翻译自己编写的提示、必要背景和回复，再提交 Hub。Hub 不调用翻译模型，不猜测正文语言，不自动重发或增加消息。附件、代码、路径、标识符、原始材料和必须逐字保留的引用不翻译，也不复制完整原文与译文两份上下文。

## 数据与规则

Endpoint 增加 `communication_language`。空值或 `auto` 表示默认；`claude-code`/`claude` 默认 `en`，其余默认 `auto`。支持语言代码及可选脚本和地区，例如 `en`、`zh-Hans`、`nb`、`pt-BR`，只接受结构化标签，不接受自由提示词。

一次发送的规则按顺序选择：收件方 Claude 的选择、发件方 Claude 的选择、收件方显式选择、发件方选择；均为 `auto` 时由 Agent 按任务合理决定。两个 Claude 的选择不同时，以收件方为准。成员目录返回每个成员的配置和相对当前调用方的 `send_language`。远端已签名目录携带 driver 与语言，避免用同名 endpoint 猜产品类型。

消息保存简短的 `communication_language` 提示，不修改正文。新设置影响后续提交，历史记录和已领取的消息保持原样；重试同一 ID 返回原记录。原生固定协议包装与字段名不做模型翻译。语言是协作表达规则，不构成权限或真实性证据。

## 技能动态同步

固定英文技能模板升级一次，在旁边引用受管 `communication-policy.md`。配置文件只列当前 endpoint 和可见本机成员的语言；远端规则按需读取最新目录。UI 保存后同步已登记、未被手工修改的受管技能，不扫描新目录、不恢复已卸载技能、不覆盖用户编辑。策略文件属于安装清单，策略变化也会显示为待更新。

源技能版本和用户策略版本分别处理，避免用户切换语言触发源规则降级保护。保存成功但某处同步失败时，明确返回部分失败和受影响位置；磁盘更新不代表运行中的原生会话已经重新读取。不会为了刷新技能唤醒模型。

## UI 与验证

每张 Agent 卡提供语言选择、常用语言及自定义标签、保存按钮。中文可选；没有全局固定的人类回复语言。界面说明原始材料豁免，以及运行会话须重新读取规则。SSE 刷新保留未保存的选择。

离线测试覆盖默认英语、显式中文、语言优先级、非法配置、保存与重启、目录版本更新、跨机传播、消息重试稳定性、技能侧车同步与冲突保护、通知提示、UI 的真实请求和输入保留。测试不调用 Claude，也不把模型遵循规则的效果宣称为已验收。
